# Next release

What the next release changes, written for the people who use Incudo. Each change adds its entry here; the release's
notes are copied from this file and it is emptied for the one after.

## Desktop

- **Change a character's kind.** A character card in the library has a new **Change kind…** button, so a character
  imported from Aurora as a player character can become an NPC or a Legendary Creature (or back) without rebuilding it.
  Before anything changes, Incudo lists exactly what the new kind does not keep (class levels, background, hit point
  rolls, prepared spells, the bag, text fields and the rest). You choose whether armour class, hit points and the other
  numbers the old sheet showed are typed in for the new one, and whether spells, skills, languages and features it no
  longer chooses are kept as added elements. Cancel changes nothing, and the file in the library changes only when you
  save.

## Phone

- The Build screen has the same **Change kind…**.
